## Description

A list of resources compiled by Workers for a New Southwest (WNS) for a teach-in hosted at the [Albuquerque Friends Meeting House](https://abqfriends.org/). WNS is a grassroots organization based in Albuquerque, New Mexico. To find out more, visit WNS's Instagram account here: [https://www.instagram.com/workersforanewsouthwest/?hl=en](https://www.instagram.com/workersforanewsouthwest/?hl=en). This website was coded _pro bono_ to support local activism.

**_Accessibility rating_** by Lighthouse audit: ---/100 for desktops and ---/100 for mobile devices.
