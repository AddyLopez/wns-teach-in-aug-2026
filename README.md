# WNS Teach-In (Aug. 2026)

**_View this project:_** [https://wns-teachin-nm-and-the-war-economy.netlify.app/](https://wns-teachin-nm-and-the-war-economy.netlify.app/)

## Description

A fully responsive website across small, medium, and large screen sizes. It provides various resources compiled by Workers for a New Southwest (WNS) for a public teach-in entitled, "New Mexico and the War Economy," hosted at the [Albuquerque Friends Meeting House](https://abqfriends.org/). WNS is a grassroots organization based in Albuquerque, New Mexico. To find out more, visit WNS's Instagram account here: [https://www.instagram.com/workersforanewsouthwest/?hl=en](https://www.instagram.com/workersforanewsouthwest/?hl=en). This website digitally archives the event and WNS's work. I coded it _pro bono_ to support local activism in service of a more peaceful society.

**_Accessibility rating_** by Lighthouse audit: 100/100 for desktops and 100/100 for mobile devices.
